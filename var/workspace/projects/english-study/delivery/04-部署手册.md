# English-study 部署手册

## 1. 文档目的

本文档说明 English-study 当前仓库形态下的建议部署方式、关键配置项、启动入口和最小验收步骤。

## 2. 适用范围

适用于当前源码仓库：

- `projects/english-study/repo`

当前版本更适合“源码运行与继续开发”，不适合作为已经固化的正式安装包或官方镜像直接交付。

## 3. 部署前提

### 3.1 基础环境

建议准备：

- Python 3.8+
- Poetry
- 可用数据库（SQLite / PostgreSQL / MySQL 其一）
- Linux 开发或测试环境

### 3.2 当前已知限制

在部署前，需要注意：

- `label_studio/core/settings/base.py` 当前存在语法异常
- `label_studio/server.py` 当前存在疑似截断问题
- 因此完整启动前，应先修复源码异常

## 4. 目录说明

- `label_studio/manage.py`：Django 管理入口
- `label_studio/server.py`：CLI/服务入口
- `label_studio/core/settings/base.py`：基础配置
- `pyproject.toml`：依赖与脚本入口
- `README.md`：本地仓库定位说明

## 5. 安装步骤

### 5.1 安装依赖

```bash
cd projects/english-study/repo
pip install poetry
poetry install
```

### 5.2 初始化数据库

```bash
python label_studio/manage.py migrate
```

### 5.3 收集静态资源

```bash
python label_studio/manage.py collectstatic
```

### 5.4 启动服务

```bash
python label_studio/manage.py runserver
```

或使用脚本入口：

```bash
label-studio
```

## 6. 关键配置项

根据 `label_studio/core/settings/base.py`，部署中优先核对以下变量：

### 6.1 地址与调试

- `HOST`
- `DEBUG`

### 6.2 数据目录

- `BASE_DATA_DIR`

若未指定，则系统会使用默认运行数据目录。

### 6.3 数据库

可选数据库包括：

- SQLite
- PostgreSQL
- MySQL

相关环境变量包括：

- `DJANGO_DB`
- `POSTGRE_USER`
- `POSTGRE_PASSWORD`
- `POSTGRE_NAME`
- `POSTGRE_HOST`
- `POSTGRE_PORT`
- `MYSQL_USER`
- `MYSQL_PASSWORD`
- `MYSQL_NAME`
- `MYSQL_HOST`
- `MYSQL_PORT`

## 7. 默认行为

- 默认内部端口：`8080`
- 默认数据目录：运行时自动生成
- 默认数据库策略：按环境变量决定，代码中保留 SQLite / PostgreSQL / MySQL 支持

## 8. 最小验收步骤

在源码问题修复后，建议按以下顺序验收：

1. 执行 `python3 -m py_compile` 检查核心入口文件
2. 执行数据库迁移
3. 启动 Django 服务
4. 浏览器访问首页
5. 创建测试项目
6. 检查模型连接入口是否存在
7. 导入一批测试任务
8. 完成一条标注并尝试导出结果

## 9. 浏览器冒烟建议

修复源码问题后，建议补一个简单 Playwright 冒烟，覆盖：

- 首页可打开
- 核心静态资源正常返回
- 登录页或项目列表页可见
- 无首屏致命报错

## 10. 回滚建议

部署前务必保留可回滚 git 版本。建议至少保留两类提交点：

- 文档与基线整理版
- 源码修复与冒烟验证通过版

## 11. 当前结论

当前部署手册可作为后续运行验证的操作基线，但在 `base.py` 和 `server.py` 修复前，不建议直接按本文档执行正式环境部署。
