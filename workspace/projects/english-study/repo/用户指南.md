# Label Studio 使用指南

> 访问地址：http://localhost:8080

---

## 一、工具简介

Label Studio 是一款开源数据标注平台，支持多种数据类型的标注任务：

| 数据类型 | 用途 |
|---------|------|
| 文本 | 文本分类、命名实体识别、情感分析 |
| 图像 | 目标检测、图像分割、关键点标注 |
| 音频/语音 | 语音分割、转录、情感识别 |
| 视频 | 视频分类、时间轴标注 |
| HTML/时间序列 | 网页标注、传感器数据 |

## 三、快速开始：完整测试流程

### 步骤 1：注册/登录

1. 打开 http://localhost:8080
2. 首次使用点击「创建账号」，填写邮箱和密码
3. 登录后进入项目列表页

---

### 步骤 2：创建项目

1. 点击右上角「创建项目」
2. 填写项目名称（如：语音标注测试）
3. 点击「数据导入」标签页 → 可先跳过，后续导入
4. 点击「标注设置」标签页 → **这是核心配置**
5. 从左侧模板列表选择任务类型（见下方模板说明）
6. 点击「保存」完成创建

---

## 四、标注模板详解

### 4.1 文本分类

**适用场景**：判断文本属于哪个类别（正面/负面/中性）

**配置示例**：
```xml
<View>
  <Text name="text" value="$text"/>
  <Choices name="sentiment" toName="text">
    <Choice value="正面"/>
    <Choice value="负面"/>
    <Choice value="中性"/>
  </Choices>
</View>
```

**操作步骤**：
1. 阅读中央区域显示的文本
2. 在右侧点击对应类别按钮
3. 点击「提交」进入下一条

---

### 4.2 命名实体识别（NER）

**适用场景**：标记文本中的人名、地名、机构名等

**操作步骤**：
1. 先在右侧标签面板选择标签类型（如「人名」）
2. 用鼠标在文本中拖选目标词语
3. 选中后自动创建标注区域
4. 可在大纲面板查看所有已标注实体
5. 点击「提交」

---

### 4.3 图像目标检测

**适用场景**：在图像中框选目标物体

**工具栏说明**：
- 矩形框工具：拖拽画矩形
- 多边形工具：点击画多边形轮廓
- 椭圆工具：拖拽画椭圆
- 关键点工具：点击标记关键点
- 画笔工具：自由涂抹分割区域

**操作步骤**：
1. 在顶部工具栏选择标注工具
2. 在右侧选择标签类别
3. 在图像上拖拽/点击创建区域
4. 双击区域可修改标签
5. 点击「提交」

---

### 4.4 音频/语音标注（重点）

**适用场景**：语音分割、转录、情感识别

**界面说明**：
```
┌─────────────────────────────────────────────┐
│  波形图显示区域                               │
│  ████████████████████████████████████████   │
│  ▲                                          │
│  播放头                                      │
├─────────────────────────────────────────────┤
│  [▶ 播放] [⏹ 停止]  速度: [1x▼]            │
│  水平缩放: [─────●──────]                   │
│  垂直缩放: [──●─────────]                   │
└─────────────────────────────────────────────┘
```

**操作步骤**：
1. 点击「▶ 播放」收听音频
2. 在波形图上**拖拽**选择一段时间区间
3. 在右侧标签面板选择标签（如「语音」「噪音」「静音」）
4. 重复操作标注所有片段
5. 若需转录：在详情面板的文本框输入对应文字
6. 点击「提交」

**快捷键**：
| 快捷键 | 功能 |
|--------|------|
| 空格键 | 播放/暂停 |
| Ctrl+Enter | 提交标注 |
| Ctrl+空格 | 跳过任务 |
| ← → | 前进/后退 5 秒 |

## 五、数据导入

### 支持格式

| 格式 | 说明 |
|------|------|
| JSON | 推荐格式，支持预标注 |
| CSV | 表格数据 |
| TXT | 纯文本，每行一条 |
| 图片文件 | JPG/PNG/GIF |
| 音频文件 | MP3/WAV/OGG/FLAC |
| 视频文件 | MP4/WebM |

### 导入步骤

1. 进入项目 → 点击「导入」按钮
2. 拖拽文件到上传区域，或点击选择文件
3. 也可粘贴 URL 列表（每行一个）
4. 点击「导入」确认
