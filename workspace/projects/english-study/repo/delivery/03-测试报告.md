## 5. 关键验证结论

### 5.1 文档与身份面

当前仓库已完成以下收口：

- `README.md` 已明确这是 English-study 的裁剪工作仓库
- 本地项目设置文档已改为自包含写法
- `pyproject.toml` 中作者信息已改为 `English-study maintainers`
- 模型后端、预测和交互式预标注等说明仍然保留

### 5.2 运行入口

当前可以确认的入口包括：

- `label_studio/manage.py`
- `label_studio/server.py`
- `pyproject.toml` 中的脚本 `label-studio = "label_studio.server:main"`

### 5.3 运行修复与复测结果

第二阶段修复中，确认当前 English-study 快照不是单点文件错误，而是存在成批缺失和占位文本污染。修复动作包括：

- 从官方 `label-studio==1.13.1` wheel 恢复 `label_studio/core/settings/base.py`、`label_studio/server.py`、`label_studio/core/settings/__init__.py`、`label_studio/core/settings/label_studio.py`
- 从官方 `label-studio==1.13.1` source tarball 重建 `pyproject.toml`，同时保留 `English-study` 的 description 和 authors 定制
- 批量补回当前快照缺失的 `label_studio/` 与 `web/` 必要文件，不覆盖已存在的 English-study 自定义文件
- 修复仍带有读取占位文本的运行时关键文件，例如 `label_studio/ml/api.py`
- 在 Python 3.12 环境下把 `setuptools` 降到可提供 `pkg_resources` 的版本，解除启动兼容问题
- 为 Playwright 的 Chromium 提供本地浏览器目录与用户态共享库路径，避免依赖系统级 root 安装

复测结果：

- `python3 -m compileall -q label_studio` 通过
- `python manage.py check` 通过
- `python manage.py migrate --noinput` 通过
- 本地服务可启动，`curl http://127.0.0.1:18080` 返回 `302` 跳转到 `/user/login/`
- Playwright 可打开 `http://127.0.0.1:18080/user/login/`，返回 `200`，页面标题为 `Label Studio`，登录文案可见

### 5.4 文档导出能力

当前环境已具备一条轻量 Word 导出链路：

- 工作区 `doc-tools` venv 中的 `python-docx` 可用
- 已新增 `projects/english-study/tools/export_delivery_docs.py`
- 当前交付文档可导出到 `projects/english-study/delivery/docx/`

仍未具备的工具包括：

- `pandoc`
- `soffice` / `libreoffice`

因此当前 Word 交付采用本地脚本导出方案，复杂排版如需完全还原，仍建议人工抽查一次版式。
