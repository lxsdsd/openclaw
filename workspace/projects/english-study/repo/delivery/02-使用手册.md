# English-study 使用手册

## 1. 文档目的

本文档面向管理员、标注员和审核员，描述 English-study 当前交付版本的标准使用方式。

建议访问地址：`http://localhost:8080`

## 2. 产品简介

English-study 是基于 Label Studio 定制的英语学习数据标注与复核平台，当前版本重点支持：

- 项目创建与任务管理
- 音频、文本等英语学习任务的标注与复核
- 任务导入与结果导出
- 模型接入、预测拉取和预测辅助标注

## 3. 角色说明

### 3.1 管理员

负责：

- 创建项目
- 配置标注模板
- 连接模型后端
- 导入任务
- 分配成员
- 导出结果

### 3.2 标注员

负责：

- 领取任务
- 根据规范完成标注
- 记录不确定项
- 提交标注结果

### 3.3 审核员

负责：

- 复核标注结果
- 退回问题样本
- 维护标注一致性
- 检查模型辅助结果是否被误用

## 4. 快速开始

### 4.1 登录系统

1. 打开系统地址
2. 输入账号和密码
3. 进入项目列表页

### 4.2 创建项目

1. 点击创建项目
2. 填写项目名称和描述
3. 在项目说明中写清任务目标、标签定义和验收规则
4. 配置标注界面
5. 如需模型辅助，进入模型区域连接后端
6. 保存项目

### 4.3 导入任务

1. 进入目标项目
2. 打开导入页面
3. 上传任务文件或配置数据源
4. 检查字段映射
5. 抽查首批任务内容

## 5. 标注流程

### 5.1 领取任务

- 进入任务列表
- 打开待处理任务
- 先阅读任务说明，再开始标注
- 遇到坏样本、字段缺失或异常内容时，按项目规则跳过并记录原因

### 5.2 完成标注

- 按标签定义进行标注
- 不确定样本优先标记疑问，不要凭猜测提交
- 提交前检查必填字段、标签一致性和备注

### 5.3 使用模型辅助

若项目已连接模型，界面中可能显示预测结果或辅助建议。请遵循以下原则：

- 模型预测只作为辅助，不等同于最终结果
- 关键结论必须人工确认
- 预测明显错误时，以人工判断修正
- 若预测持续异常，反馈管理员检查模型配置

## 6. 复核流程

审核员应重点检查：

- 标签是否符合项目定义
- 关键字段是否漏标
- 音频或文本分段是否符合规范
- 模型辅助结果是否被直接当成最终裁决
- 是否存在批量复制、明显误点或一致性异常

## 7. 项目配置要点

根据当前本地文档，项目中常见配置区域包括：

- General
- Labeling interface
- Annotation
- Review
- Quality
- Members
- Model
- Predictions
- Cloud storage
- Webhooks
- Danger Zone

其中模型相关配置包含：

- Connect Model
- Start model training on annotation submission
- Interactive preannotations
- Imported predictions and live predictions

## 8. 导出结果

1. 打开项目导出页面
2. 选择业务需要的格式
3. 检查是否包含人工标注、预测字段和审核字段
4. 导出后记录批次、时间和责任人

## 9. 常见问题

### 9.1 看不到模型入口

请联系管理员确认：

- 项目是否已连接模型
- 当前账号是否有查看模型配置的权限

### 9.2 预测结果不显示

请检查：

- 模型连接是否成功
- 项目是否开启预测展示
- 当前任务是否已执行预测拉取

### 9.3 任务无法提交

请检查：

- 必填标签是否完成
- 字段映射是否正确
- 网络请求是否失败

若问题持续，请记录任务编号并联系管理员。

## 10. 操作建议

- 项目说明与标签定义要保持同步
- 批量导入后先抽样检查，再大规模发任务
- 模型辅助必须保留人工复核兜底
- 导出前至少做一次抽检
- 重要配置变更应写入变更记录
